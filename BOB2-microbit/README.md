# BOB2共通ファームウェア

4台すべてのBOB2 micro:bitへ同じ`BOB2mbit-common.hex`を書き込みます。ソースは`main.ts`です。

- 初回IDは99（未設定）。LEDには数字の9を固定表示
- 待機中にA+Bを押すと `99 → 0 → 1 → 2 → 3 → 0` の順で変更
- IDは不揮発領域へ保存
- A+Bで変更したIDとBLE接続時のIDを `ID,n` でMBPへ通知
- A=両腕を上げて保持、B=IDを2秒表示、ロゴ=両腕を下げて右0.2秒→左0.4秒→右0.2秒（LEDは変更しない）
- ゲーム中は本体ボタンとID変更を無効化
- LED状態は、未接続=`×`、接続済み待機=ランダム模様、選択=`✓`、`3→2→1→GO`、演技中=Happy、演技終了=消灯
- 全演技後は全台で2秒間の輪アニメーションを行い、0〜4点分だけ左から◎を表示する。その後3秒間バイバイしてランダム待機へ戻る

## コマンド

```text
0,パターン,レベル  模範演技（パターン0はID 0=バイバイ、1=左右ふりふり、2=上でパーン、3=変なおじさん）
1,対象ID           対象BOBがIDを5秒表示後に消灯
2,評価コード,得点  0=泣き顔、1=△、2=○、3=◎
3,最終点数         0〜4点。輪アニメーション後、IDが点数未満のBOBに◎を表示
4                  中断・車輪停止・LED消去（腕角度は維持）
5                  初期位置（車輪停止、両腕30度、ランダム表示）
6,テスト番号      0=A/両腕上げ保持、1=B/IDを2秒表示、2=ロゴ/両腕下げ＋右0.2秒→左0.4秒→右0.2秒
7                  全台で3秒間バイバイ後、ランダム待機表示へ戻る
```

## 車輪の出力極性

```text
          P13 P14 P15 P16
前進       1   0   0   1
後退       0   1   1   0
左回り   0   1   0   1
右回り   1   0   1   0
停止       0   0   0   0
```
